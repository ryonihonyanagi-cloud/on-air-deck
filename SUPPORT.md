# Support

## Setup questions

Use GitHub Discussions after the public repository is created.
Include the ON AIR Deck version, macOS version, Mac model, microphone or interface, selected input channel, destination app, and whether the problem affects `LIVE`, `REC`, or both.

## Bugs

Use the bug report template.
Do not upload private recordings or logs containing personal information.

## Security and conduct

Follow `SECURITY.md` for vulnerabilities.
Do not disclose conduct incidents in a public issue.

## Before asking for help

1. Confirm that ON AIR Deck’s microphone meter moves when you speak.
2. In `LIVE`, confirm that the virtual microphone status is ready.
3. In Zoom, Meet, or OBS, select `ON AIR Deck` as the microphone.
4. Use wired headphones before enabling voice monitoring.
5. If the virtual microphone is missing, reinstall the release-matched driver and restart audio applications.
