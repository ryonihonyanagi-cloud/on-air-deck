# プロジェクトライセンス決定記録

決定日: 2026-08-11  
決定: MIT License  
著作権表示: `Copyright (c) 2026 Ryo Nihonyanagi`

正式な許諾条件は、ルートの`LICENSE`を正本とします。

## 選定理由

- 個人開発者が理解しやすい簡潔なライセンスです。
- 商用利用、改変、再配布、サブライセンスを広く許可します。
- Apple由来ドライバコードの同梱MITライセンスと方向性を揃えやすいです。
- 派生版のソース公開を義務づけません。

## ライセンスと素材の境界

プロジェクトのMIT Licenseはソースコードへ適用します。
同梱音源やアートワークへ自動的に同じ条件が適用されるわけではありません。

音源と画像は、`THIRD_PARTY_NOTICES.md`と公開前の素材台帳で個別に権利を確定します。

Apple由来のドライバコードは、`AudioDriver/APPLE-SAMPLE-LICENSE.txt`と`AudioDriver/LICENSE.txt`に含まれる原著作権表示と許諾表示も維持します。

## 配布物への同梱

アプリのバイナリ配布物にも、プロジェクトの`LICENSE`、`THIRD_PARTY_NOTICES.md`、Appleサンプルコードのライセンス表示を同梱します。
